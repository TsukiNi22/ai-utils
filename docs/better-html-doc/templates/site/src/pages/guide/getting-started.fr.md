Ce qu'il faut, l'installation, le premier lancement.

## Installation {#install}

```bash "Terminal"
./setup.sh install
```

> [!NOTE]
> L'installation ne demande pas d'accès root.

## Premier lancement {#first-run}

1. Lancez-le : `{{PROJECT}}`.
2. Appuyez sur <kbd>?</kbd> pour les touches.

Ensuite : [la configuration](page:configuration#files).
