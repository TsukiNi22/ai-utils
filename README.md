# Graph explorer

Published with GitHub Pages: **https://tsukini22.github.io/skills/**

The project graph of the [`html-doc`](https://github.com/TsukiNi22/skills/blob/main/docs/html-doc/SKILL.md) skill
for any public GitHub or GitLab repository: give its link and the page reads its sources in the browser to draw its
files, classes, functions, calls, tests and packages (2D / 3D graph, execution flow, inheritance tree, flame graph).

- `graph.html`: the explorer, generated by `docs/html-doc/scripts/build_explorer.mjs` of the `main` branch.
- `index.html`: redirects to `graph.html` (the query string is kept: `?repo=owner/name` opens a repository).

The link of the repository stays editable in the panel and is remembered by the browser until Ctrl + Shift + F3.
