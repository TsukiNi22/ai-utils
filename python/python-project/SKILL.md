# Python project

`SKILL_DIR` = the directory of this file. The code follows `python-style` (load it). Generator:
```bash
python3 SKILL_DIR/scripts/new_project.py <name> --kind script|app|package --dir <parent> --desc "<one line>" \
    [--python 3.12] [--version 1.0.0] [--banner xartania|none|<text>]
```

## 1. Ask (one AskUserQuestion call, French) - only what the request doesn't say
- **Type**: `Package installable (Recommandé pour un outil / une lib)` · `Application (structure MAGIC)` ·
  `Script seul`.
- **Nom** (folder, distribution and command name; the package is the name in lower case with `_`), **description**,
  **version Python minimale** (default: the installed one, `python3 --version`, at least 3.10 for `X | None`).
- **Extras** (multiSelect): `Tests pytest` · `CI (ci-workflows)` · `README (readme-style)` · `Licence (license)` ·
  `git init + premier commit (git-conventions)`.

## 2. Layouts
| Kind | Files | Run |
|---|---|---|
| `package` | `pyproject.toml`, `src/<pkg>/{__init__,__main__,const,exception,main}.py`, `tests/test_main.py` | `pip install -e ".[dev]"` then `<name>` / `python -m <pkg>`, `pytest` |
| `app` (MAGIC) | `src/main.py` (entry, guards, exit codes), `src/app.py` (setup + main loop), `src/const.py`, `src/Class/` (one class per file), `src/tool/` (one function per file, named like it), `data/` (runtime files), `requirements.txt` | `python3 src/main.py` |
| `script` | `<name>.py` (`##### Program #####` at module level), `const.py` | `python3 <name>.py` |
Every kind gets `.gitignore` (venv, caches, build outputs) and a `README.md` stub to finish with `readme-style`.

- **Version**: one source, `VERSION = "x.y.z"` at the top of `const.py` (a literal: setuptools reads it without importing),
  reused by `VALUES.VERSION`, `__version__` and `--version`; bumped with the CHANGELOG (`git-conventions`).
- **`__init__.py`**: the version and the public API only (`__all__`), no logic, no side effect at import.
- **`__main__.py`**: `exit(main())`, so `python -m <pkg>` and the console command (`[project.scripts]`) are the same.
- **`main.py`**: `main(arguments: list[str] | None = None) -> int` (testable without `sys.argv`), `argparse` with
  `--version`, the program in a `try` catching `ProjectError` (message on stderr, its code returned) and
  `KeyboardInterrupt`; returns `RETURN.OK`. Never `exit()` inside a package except in `__main__.py`.
- **`exception.py`**: `ProjectError(message, code=ERROR.ACTION, info="[None]")` with `formated()` (`[Error] message ->
  info`, the reading of the libutils exceptions); project specific errors inherit from it.
- **`const.py`**: the frozen dataclasses of `python-style` (`Return`, `Error`, `Values`, `Files`...) and their instances.
- Dependencies: `pyproject.toml` `dependencies` (package) or `requirements.txt` pinned with `==` (app); development
  tools in the `dev` extra. A virtual environment `.venv` (`python3 -m venv .venv`), never `sudo pip`.
- Data files of an application: relative to the project root through `FILES` in `const.py`, never hard-coded in the
  code (MAGIC's `data\\parameters.save` Windows paths: `pathlib` instead).

## 3. After the generation
1. Fill `const.py` (names, files, values), write the code with `python-style`, one module per concern.
2. Tests: `tests/test_<module>.py` with `pytest` (the `tests` skill for more), run them in the venv.
3. Check: `xstyle -r .` (generic + `PY-*` rules), fix with `xstyle --fix`.
4. Extras chosen: `readme-style`, `license`, `ci-workflows` (`templates/python.yml`), `git-conventions` (first commit
   `feat: initial version of <name>` only if the user asked for the commit).
