    Configuration referenceRéférence de configuration

    Every section and key of config.toml with its default - generated from the template shipped in the binary.Chaque section et clé de config.toml avec son défaut - générée depuis le modèle embarqué dans le binaire.

    ~/.config/claude-cluster/config.toml is written, commented, on the first run and reloaded live when saved. Every key is optional: a missing key keeps its default. This page is generated from templates/config.toml: the defaults and the comments are those of the file. The same options with their labels are in the settings reference; the key bindings are in the keys reference.

    ~/.config/claude-cluster/config.toml est écrit, commenté, au premier lancement et rechargé à chaud quand il est sauvegardé. Chaque clé est optionnelle : une clé absente garde sa valeur par défaut. Cette page est générée depuis templates/config.toml : les valeurs par défaut et les commentaires sont ceux du fichier. Les mêmes options avec leurs libellés sont dans la référence des réglages ; les touches sont dans la référence des touches.

    Les commentaires viennent du fichier, en anglais.
