# Python skills

Python the way I write it (my scripts, MAGIC): a project (script, application or installable package),
files and classes scaffolded with empty bodies, the style and the comments, checked by the `PY-*` rules of
`xstyle`. Router: [`/python`](../routers/python/SKILL.md).
