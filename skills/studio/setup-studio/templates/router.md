## How to route
- Read what is produced (a sound, an image, a video, a 3D model, a simulation or a render), from what, for what use.
- Load the skill of **every** domain the request touches (Skill tool): a video with music and a voice-over =
  `studio-video` + `studio-audio`; an animation with smoke = `studio-3d` + `studio-vfx`; a thumbnail from a render =
  `studio-3d` + `studio-image`.
- Unclear (format, length, style, resolution, commercial use, quality against time): `clarify` /
  `interactive-questions` first; ideas wanted: `ideation`.
- Follow the *Which tool for what* table of the skill; a task no installed tool covers: its *Missing* part (propose the
  free tool, install only after a yes) or `/setup-studio` to add it.
