Trust this computer once

The browser warns because this computer made its own certificate (a local network has no public one). Install its authority once on this device: its pages open without warning, and stay encrypted.

Android
  1. Download it (above).
  2. Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate.
  3. Pick claude-cluster-ca.crt, then reload this page.
iPhone / iPad
  1. Download it (above), then Settings › Profile downloaded › Install.
  2. Settings › General › About › Certificate Trust Settings: turn on claude-cluster.
Firefox (any system)
  1. Download it, then Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import.
  2. Tick Trust this CA to identify websites.
Windows / macOS / Linux (Chrome, Edge, Safari)
  1. Windows: open the file › Install › Local machine › Trusted Root Certification Authorities.
  2. macOS: open it in Keychain Access › System › Always trust.
  3. Linux: sudo trust anchor --store claude-cluster-ca.crt (on the computer of claude-cluster itself: its palette, Web access: trust its certificate).
